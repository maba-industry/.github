# 마바산업 (MABA Industry)

> 30년 모빌리티 데칼 전문기업, SW로 영역을 넓혀갑니다.

## About

마바산업은 1996년 설립 이후 30년간 모빌리티 데칼·랩핑 분야의 
전문성을 쌓아왔습니다. 최근에는 차량용 소프트웨어와 디지털 
솔루션 영역으로 사업을 확장하고 있습니다.
